它是什么

WireGuard 管理台（WireGuardManager）是一个 Windows 桌面版 WireGuard 管理工具：通过 SSH 直接管理服务器上 wg0.conf 里的 peer（查看、增删改、二维码、热加载、失败回滚），同时托管本机隧道（连接 / 断开 / 实时速率）。它不需要在服务器部署 Web 面板、Docker 或数据库，直接操作你已有的标准 wg-quick 配置，另附「一键装服务端」。单文件免安装，开源。

它和其他 WireGuard 管理方案的区别

方案运行位置服务端要额外装东西吗适合谁
WireGuard 管理台（本项目）Windows 桌面程序不用，直接 SSH 改现有的 wg0.conf已有 wg-quick 部署、想图形化管理 peer 的人
官方 WireGuard 客户端Windows / 手机 / macOS / Linux不用只负责连接隧道，不管理 peer
wg-easy / WGDashboard / wg-portal服务器上的 Web 面板要（Docker / Go / 数据库）团队自助、多用户、要发配置给很多人
Netmaker / Tailscale / Headscale服务器或云端要mesh 组网、自动 NAT 穿透、多节点互联

一句话差别：本工具把「管理 WireGuard peer」这件事留在你的 Windows 电脑上，服务端保持标准 wg-quick 不变。

适合

  • 已有可用的 WireGuard 服务端，不想再塞 Docker、数据库或 Web 面板
  • 要给同事 / 客户批量加 peer，不想手敲 wg set 和改 AllowedIPs
  • 要扫码发配置，不想在聊天工具里来回传 .conf
  • 想在 Windows 上一键连 / 断隧道、实时看速率
  • 服务器还没装 WireGuard，想图形界面一键装

不适合

  • 需要 LDAP / OIDC / SSO / 多租户 → wg-portal / DefGuard
  • 需要 mesh 组网、自动打洞 → Netmaker / Tailscale
  • 服务端是新版 wg-easy（peer 存数据库）→ 改文件未必生效
  • 需要 Windows 服务端 / macOS / Linux 桌面端 → 本工具只做 Windows

加 peer 的三步

1. 填服务器 IP / SSH 端口 / 用户名 → 点「连接」，工具自动探测 wg0.conf、监听端口、VPN 网段
2. 点「新增密钥」→ 自动分配地址、生成密钥对、写入配置、热加载 → 弹出二维码
3. 手机 WireGuard App「扫描二维码」导入，完事
注意：二维码里的客户端私钥是凭据本身，扫完别把它贴到公开的地方。

服务器还没装 WireGuard？

连上去发现是「裸机」时，工具不会只丢一句「没找到配置文件」，而是弹出安装方案：选网段、选端口、选出口网卡、要不要写 NAT 规则，确认后自动装包、建配置、开转发、起服务，装完自动重新探测并进入管理界面。

支持 Ubuntu / Debian / Mint / Kali / Deepin / UOS / Armbian / 树莓派 OS、RHEL 9 / Rocky / Alma / CentOS Stream / Fedora、RHEL 8 系（走 EPEL + ELRepo）、Arch / Manjaro / openSUSE。Debian 10 及更早、CentOS 7、Alpine 等非 systemd 系统会明确拒绝安装，并逐条给出手动命令。

安全设计

备份 wg0.conf
   ↓
写临时文件（umask 077）
   ↓
cp + mv 原子替换（不会出现半截文件）
   ↓
wg-quick strip + wg syncconf 热加载（不中断现有连接）
   ↓
回读文件校验 + 运行时公钥核对
   ↓
任何一步失败 → 自动恢复备份并重新加载
私钥归属
客户端私钥只在本机生成，服务端只存公钥；私钥不出现在命令行，临时文件权限 600
本地存储
connections.json / tunnels.json 用 Windows DPAPI 加密，不明文落盘
主机指纹
SSH 指纹 TOFU 记录到 known_hosts，指纹变化直接拒绝连接
日志脱敏
PrivateKey / PresharedKey / password 一律替换为 ***
网络行为
工具不联网、不上报数据，只在你点「连接」时通过 SSH 直连你的服务器

下载

⬇ 安装版 WireGuardManager-setup.exe ⬇ 单文件版 WireGuardManager.exe

两种发行版功能完全相同，下载链接永久固定（releases/latest/download/...）。安装版装完启动约 1 秒；单文件版首次启动约 5 秒（要把 49 MB 运行库解压到 %TEMP%），换来的是免安装和程序内自动更新。

校验值：SHA256.txt（与 exe 同目录）。

没有代码签名：Windows SmartScreen 会提示「未知发布者」，选「更多信息 → 仍要运行」。这是本项目当前最大的已知限制。
